# Сайт АНО ЦДО «ОРИОН» имени Бигаева М.А.

Добро пожаловать в проект современного и безопасного детского сада! Этот сайт разработан на базе современного стека технологий **Next.js**, что позволяет обеспечить высокую скорость работы, безопасность данных и интерактивность (чат, личный кабинет).

## 🚀 Как запустить сайт локально

Для запуска вам понадобится установленный **Node.js** (версия 18 или выше).

### Windows:
1. Просто запустите файл `start.bat` двойным кликом.
2. Скрипт сам установит все необходимые библиотеки и настроит базу данных.
3. После завершения работы скрипта, откройте в браузере: `http://localhost:3000`

### Linux / macOS:
1. Откройте терминал в папке проекта.
2. Запустите: `bash start.sh`
3. Откройте в браузере: `http://localhost:3000`

## 📁 Структура проекта

*   `static_previews/` — **Здесь находятся обычные HTML-файлы** для быстрого просмотра дизайна без запуска сервера.
*   `src/app/` — Исходный код страниц сайта (логика чата, базы данных, авторизации).
*   `prisma/` — Конфигурация базы данных.
*   `public/` — Статические изображения и файлы.

## 🌟 Основные возможности

1.  **Главная страница:** Информация о ЧВК «Вектор», бункере, робототехнике и курсах выживания.
2.  **Островок событий:** Лента новостей, доступная только авторизованным родителям и учителям.
3.  **Поступление:** Интерактивная форма подачи заявления.
4.  **Личный кабинет:** Просмотр расписания ребенка и связь с воспитателем.
5.  **Чат:** Групповые чаты для каждой группы детского сада.
6.  **Админ-панель:** Просмотр входящих заявок и ручная регистрация новых пользователей.
