# Инструкция по запуску сайта АНО ЦДО «ОРИОН»

Сайт разработан на стеке Next.js, Tailwind CSS и Prisma.

## Требования
- Node.js (версия 18 или выше)
- npm

## Быстрый запуск
1. Распакуйте архив с проектом.
2. Запустите файл `start.sh` (для Linux/Mac) или `start.bat` (для Windows).
3. После запуска сайт будет доступен по адресу: `http://localhost:3000`

## Структура сайта
1. **Главная**: Общая информация, ЧВК «Вектор», бункер и т.д.
2. **Заявка**: Форма для родителей.
3. **Вход**: Личный кабинет для родителей и учителей.
4. **Админка**: Доступна по адресу `/admin-hidden-panel` (требуется вход под админом).
5. **Островок событий**: Доска новостей для авторизованных пользователей.

## Ручное управление
Если вы хотите управлять проектом вручную:
- `npm install` — установка зависимостей.
- `npx prisma db push` — инициализация базы данных.
- `npm run dev` — запуск в режиме разработки.
- `npm run build` — сборка для продакшена.
