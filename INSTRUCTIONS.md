# Инструкция по запуску сайта АНО ЦДО «ОРИОН»

Сайт разработан на стеке Next.js, Tailwind CSS и Prisma (SQLite).

## 🛠 Требования
1. **Node.js**: Версия 18.0 или выше.
   - Скачать: [https://nodejs.org/](https://nodejs.org/) (рекомендуется версия LTS)
2. **npm**: Устанавливается вместе с Node.js.

## 🚀 Быстрый запуск
1. Распакуйте архив с проектом в отдельную папку.
2. Запустите файл:
   - **Windows**: `start.bat`
   - **Linux / macOS**: `start.sh` (предварительно дайте права: `chmod +x start.sh`)
3. Дождитесь установки зависимостей и появления надписи о запуске сервера.
4. Откройте в браузере: [http://localhost:3000](http://localhost:3000)

## ❓ Решение проблем

### Ошибка: "npm" не является внутренней или внешней командой
Это означает, что у вас не установлен **Node.js** или путь к нему не добавлен в системные переменные.
**Решение:**
1. Скачайте и установите Node.js с официального сайта.
2. После установки **обязательно** перезагрузите компьютер.
3. Попробуйте снова запустить `start.bat`.

### Ошибка при установке зависимостей
Убедитесь, что у вас есть доступ к интернету. Если ошибка сохраняется, попробуйте удалить папку `node_modules` и запустить скрипт снова.

## 📁 Структура проекта
- `src/app` — основные страницы и API.
- `prisma/` — схема базы данных.
- `static_previews/` — статические HTML-копии для просмотра внешнего вида без запуска сервера.
